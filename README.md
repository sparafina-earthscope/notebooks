# Notebooks

A collection of notebooks that run in GeoLab. Each folder has a README with setup instructions.

| Folder | Description |
| --- | --- |
| [3d-models](3d-models/) | Turn USGS 3DEP elevation data into 3D-printable STL terrain models. |
| [3d-vizualizations](3d-vizualizations/) | Interactive 3D terrain view of Mount St. Helens with the seismic stations of the iMUSH period. |
| [GEMS-challenge](GEMS-challenge/) | Fault mapping and geothermal candidate ranking in western Nevada for the [DOE GEMS Prize Challenge](https://www.drivendata.org/competitions/306/competition-doe-gems/) from geophysical, geodetic, seismic, and lidar data (three notebooks, uses Dask Gateway). |
| [gpu-test-phase-picking](gpu-test-phase-picking/) | Deep-learning P and S phase picking on iMUSH data with SeisBench PhaseNet, on a GPU or CPU. |
| [greens-functions](greens-functions/) | Forward modeling of Cascadia seismograms with Green's functions from Syngine: the 2001 Nisqually earthquake and an M9 megathrust scenario. |
